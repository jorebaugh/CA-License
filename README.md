# CA License Study

Offline-capable quiz / flashcard app for the USCG OUPV captain's license: Rules of the Road, Deck General & Safety, Navigation General, and official USCG NMC sample exams (ONC07).

- **App:** open the GitHub Pages site in Safari on iPad → Share → **Add to Home Screen** → open it once online. It then works offline.
- **Study guide:** `Rules_of_the_Road_Study_Guide.pdf`
